What it does

A notebook that keeps out of the way

Everything here works offline. Your notes are plain markdown files in a folder you chose — no database, no sync service, nothing to lock you in.

Vaults

Open a folder and get a real file tree, search across every note, tags, and [[wiki links]] that resolve — with backlinks showing what points here.

Real diagrams

Mermaid is bundled, not approximated: flowchart, sequence, class, state, ER, gantt, pie, journey, mindmap and gitGraph.

Real mathematics

KaTeX with the mhchem extension. Fractions, matrices, aligned environments and chemistry render as you type.

Export anywhere

HTML, PDF, Word and plain text out of the box. Add Pandoc and docx, LaTeX, EPUB, RTF and reStructuredText appear too.

Fast to drive

Command palette, quick open, a slash menu for blocks, auto-pairing, table tools and find-and-replace with regular expressions.

Never lose work

Autosave to disk, file watching with conflict prompts, and version history you can walk back through — a snapshot on every save.

Rendered inline

Diagrams and equations, as you type

Sequence, state, class and ER diagrams Gantt charts, pie, mindmaps, gitGraph Full LaTeX, including chemistry Baked into every PDF and HTML export
Two builds

One editor, two shapes

The same editing model and the same markdown engine. They differ only in what the surrounding application is allowed to do.
