What it does

Everything below works offline. No accounts, no telemetry, no network calls — your notes are plain markdown files on your own disk.

📁

Vaults

Open a folder and get a real file tree, search across every note, tags, and [[wiki links]] that resolve — with backlinks showing what points here.

⤳

Real diagrams

Mermaid is bundled, not approximated: flowchart, sequence, class, state, ER, gantt, pie, journey, mindmap and gitGraph.

∑

Real maths

KaTeX with the mhchem extension. Fractions, matrices, aligned environments and chemistry all render as you type.

⤓

Export anywhere

HTML, PDF, Word and plain text out of the box. Install Pandoc and docx, LaTeX, EPUB, RTF, reStructuredText and MediaWiki appear too.

⌘

Fast to drive

Command palette, quick open, slash menu for blocks, auto-pairing, table tools and find-and-replace with regex.

🕘

Never lose work

Autosave to disk, file watching with conflict prompts, and version history you can walk back through — one snapshot per save.

Diagrams and equations, rendered inline

Both libraries ship inside the app and load from disk, so a diagram renders the same on a plane as it does at your desk.

Built to be inspected

The markdown parser, the block editor, the maths fallback and the flowchart renderer in the light build are all hand-written and readable. In the desktop app the renderer runs sandboxed with context isolation on and a content-security policy that allows scripts from the app itself only — it has no require, no fs, and no direct IPC. Deletes go to the system Trash and saves are written to a temp file and renamed, so a crash cannot truncate a note.
