# Typography

The measure is the length of a line of text. Somewhere around 66 characters
reads most comfortably — long enough for rhythm, short enough that the eye
finds the next line without hunting.

## Rhythm

Line height should grow with measure. A wide column needs more leading:

$$\text{leading} \approx 1.5 + \frac{\text{measure}}{200}$$

| Measure | Leading |
| --- | :---: |
| 45ch | 1.5 |
| 66ch | 1.72 |
| 80ch | 1.9 |
